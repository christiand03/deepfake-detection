# Daily - 2026-06-16

## Focus
Analyze the Wav2Vec2 Phase-1 (frozen) audio baseline W&B run and promote the finding to the KB.

## Progress
- **Analyzed run "Wav2Vec2 Phase 1 freezed 12.000 Data".** Headline video-level
  `val/auc_video 0.975`, `test/auc_video 0.976`. Strong frozen-backbone baseline.
- **Promoted to canonical Results note** [[Results/wav2vec2-phase1-audio-baseline]]
  (results-001) — registry + [[02-Index]] updated.
- **Key finding:** per-manipulation test AUC = audio 0.982 / both 0.984 /
  **visual-only 0.832**. Audio model can't catch purely visual fakes → motivates
  Phase-2 fusion. Same per-category breakdown should be the success test for fusion.
- **Clarified two analysis points:** (1) high-acc/low-F1 gap = operating-point +
  segment-accurate-label artifact (fake video is mostly real chunks), not a quality
  issue — report AUC/AP, tune threshold only for hard labels; (2) **not overfit**
  (val loss < train loss, test≈val, ~0.2 % params trainable, early stop epoch 16).

- **Identity-leakage check (seed 42):** verified the split is **identity-disjoint**
  (32 speakers, train 22 / val 4 / test 6, zero identity & video overlap) — no
  leakage. Found the committed data was generated with **`split_seed=11`**, while the
  code default is 42 (no config override) → reproducibility gap, not leakage.
- **Analyzed multimodal cross-attention fusion** (Phase-1, frozen) → promoted to
  [[Results/multimodal-fusion-phase1-baseline]] (results-002). Fusion lifts
  **visual-only AUC 0.832 → 0.932 (+0.10)**, acc_video +0.12, f1_video +0.12;
  aggregate auc_video dips 0.976 → 0.960 (likely noise); **now overfits**
  (train loss 0.214 < val 0.343). Linked from results-001's next-step.

- **Concat fusion ablation** → promoted to [[Results/multimodal-concat-phase1-ablation]]
  (results-003). **Cross-attention beats concat on all 8 test metrics** (visual-only
  0.932 vs 0.868) → the gain is the *mechanism*, not just bimodality. Ticked gate
  item #2 in results-002. Concat ran 38 h / 18 epochs and still lost; its val (0.962)
  overestimates test (0.934).

- **Analyzed VideoMAE P1/P2 + Wav2Vec2 P2** → new notes
  [[Results/videomae-unimodal-video-baseline]] (results-004),
  [[Results/wav2vec2-phase2-audio-end-to-end]] (results-005). **Unfreezing is decisive,
  esp. for video** (VideoMAE 0.730 frozen linear-probe → 0.999 unfrozen; Wav2Vec2 0.976
  → 0.997). Both Phase-2 unimodal models are at the clean-data ceiling → Phase 3/4 now
  carry the signal.

- ⚠️ **CORRECTION (supersedes the 0.832/+0.10 claims above).** Verified against the
  test metadata: the **cross-modal per-category AUCs for unimodal models are
  degenerate** — under `label_audio` a visual-only fake is labeled real, so that
  category has only **4** positive videos (audio model visual-only: 0.832 at P1 → 0.998
  at P2 = noise on 4 points). The audio model's "visual-only 0.832" is **retracted**;
  so is "fusion lifts visual-only +0.10 vs audio." Unimodal (`label_audio`/`label_video`)
  vs multimodal (combined `label`) are **different-label tasks**, not directly
  comparable. Corrected results-001/002/003 + the memory note accordingly. Valid:
  audio model audio 0.982 / both 0.984; fusion cross-attn 0.932 visual (273 pos) >
  concat 0.868; the *correct* visual-only baseline is the VIDEO model (0.745 → 0.999).
